# Bank Management System

A simple, interactive console-based banking application written in Python. It allows users to simulate core bank features securely inside a terminal interface.

## Features
* *Create Account:* Open a new bank account with built-in age validation.
* *Deposit Amount:* Add money smoothly to an existing balance.
* *Withdraw Amount:* Deduct money with real-time insufficient balance checks.
* *View Details:* Display comprehensive customer information and balances.

## Tech Stack
* *Language:* Python 3.x
* *Platform:* Console / Terminal Environment
